# Gemini-Hack
This project demonstrates how to integrate Google Gemini into a web application. It uses the gemini-1.5-flash model to generate content based on user inputs. You can find more details about the Gemini API [[here](https://ai.google.dev/gemini-api/docs/models/gemini)] 
If you wish to change the model, you can do so in the ```index.js``` file in the directory.


### Environment Setup
follow the env.example file before starting project make ensure you have a proper env file in project folder
